# 카카오 API 쿼터와 요금

> 출처: 카카오 개발자 쿼터 페이지 `developers.kakao.com/docs/ko/getting-started/quota` (확인일 2026-11-15, 사용자가 붙여 준 표 기준). 일간 쿼터와 요금은 바뀔 수 있다. 카카오 API를 새로 부르거나 호출 수가 바뀌는 코드를 쓰기 전에 이 문서를 읽는다.

## 일간 무료 쿼터

| 서비스 | API | 하루 무료 |
| --- | --- | --- |
| 카카오맵 REST | 키워드로 장소 검색, 카테고리로 장소 검색 | 100,000건 |
| 카카오맵 REST | 주소로 좌표 변환, 좌표로 행정구역정보 변환, 좌표로 주소 변환, 좌표계 변환 | 각 100,000건 |
| 카카오맵 REST | 대중교통·도보·자전거 경로 조회, 정적 지도 조회 | 각 1,000건 |
| 카카오맵 SDK | 지도 Android/iOS SDK, Web(JavaScript) SDK | 300,000건 (페이지 요약 기준) |
| 카카오내비 REST | 자동차 길찾기 | 10,000건 |
| 카카오내비 REST | 다중 경유지 길찾기, 미래 운행 정보 길찾기 | 각 5,000건 |
| 카카오내비 REST | 다중 출발지 길찾기, 다중 목적지 길찾기 | 각 1,000건 |
| 카카오내비 SDK | 길 안내, 목적지 공유 | 각 30,000건 |

- 카카오맵 API는 개발자 계정 기준 **첫 번째로 활성화한 앱에만** 무료 쿼터를 준다.
- 카카오맵 API 전체의 월간 무료 쿼터는 3,000,000건이다(쿼터 페이지 요약 기준).
- 쿼터는 앱 키 단위로 모든 기기가 함께 쓴다. 기기 하나에서 세는 값으로는 전체 사용량을 알 수 없다.

## 추가 쿼터 요금 (유료 API를 켠 경우)

추가 쿼터를 쓴 호출은 무료 월간 쿼터를 차감하지 않는다.

| 서비스 | API | 요금 |
| --- | --- | --- |
| 카카오맵 SDK | 지도 Web(JavaScript) SDK, Android/iOS SDK | 0.1원/건 |
| 카카오맵 REST | 주소로 좌표 변환, 좌표로 행정구역정보 변환, 좌표로 주소 변환, 좌표계 변환 | 0.5원/건 |
| 카카오맵 REST | 키워드로 장소 검색, 카테고리로 장소 검색, 정적 지도 조회 | 2원/건 |
| 카카오맵 REST | 대중교통·도보·자전거 경로 조회 | 10원/건 |

카카오모빌리티 길찾기의 초과 요금(자동차 길찾기 건당 8원 등)은 [kakao-maps](kakao-maps.md#길찾기-차량-경로만-연동)에 있다.

## 앱의 호출 수

한 번의 픽업에서 카카오 API가 몇 번 불리는지 코드로 센 값이다. 호출이 늘어나는 변경은 이 표를 같이 고친다.

| 시점 | 호출 | 카카오 API | 횟수 |
| --- | --- | --- | --- |
| 장소 검색 (`KakaoPlaceRepository.searchPlaces`) | 키워드 검색 | 카카오맵 REST 키워드 검색 | 1 |
| 장소 검색 | 후보별 거리·시간·통행료 | 카카오내비 REST 자동차 길찾기 | 최대 3 (후보 수) |
| 픽업 경로 (`KakaoRouteRepository.findPickupRoutes`) | 차량 → 픽업 지점 | 카카오내비 REST 자동차 길찾기 | 1 |
| 지도 화면 (`RouteMap`) | 지도 표시 | 카카오맵 Android SDK | 화면을 열 때마다 |

| 흐름 | 키워드 검색 | 자동차 길찾기 |
| --- | --- | --- |
| 장소를 말한 흐름 | 1 | 4 (3 + 1) |
| 장소를 말하지 않은 흐름 (추천은 가짜) | 0 | 1 |

"다시 시도"로 장소 검색을 다시 하면 그 단계의 호출이 한 번 더 나간다. 데모 주행(`DemoVehicleRepository`, `demo.drive`를 켠 빌드)은 길찾기를 1번 부른다.

## 쿼터 가드 (`core/network/quota`)

`KakaoQuotaGuard`가 기기 안에서 API별 하루 호출 수를 DataStore에 센다(한국 시간 자정에 초기화). 무료 쿼터를 넘기지 않으려고 하루 한도를 무료 쿼터의 80%로 둔다.

| 규칙 | 내용 |
| --- | --- |
| 한도 | 키워드 검색 80,000건, 자동차 길찾기 8,000건 (`KakaoApi`). 지도 SDK는 호출을 세지 못해 가드하지 않는다 |
| 사전 종료 | 흐름이 카카오 API를 부르기 전에 이 흐름에 필요한 호출 수(위 표)가 남았는지 본다. 모자라면 아무것도 부르지 않고 안내 대화상자를 띄운 뒤 흐름을 끝낸다 |
| 호출마다 | 모든 호출 전에 `tryConsume`으로 센다. 한도를 넘으면 호출하지 않는다 (키워드 검색은 흐름 종료, 길찾기는 직선거리 추정으로 대신) |
| 한계 | 기기 안의 값이라 기기가 여럿이면 전체 사용량을 막지 못한다. 앱 콘솔의 `통계 > 쿼터`로 확인한다 |
